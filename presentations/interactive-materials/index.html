Интерактивті материалды жариялау

GitHub жоба файлдарын сақтайды. GitHub Pages сол файлдардан браузерде ашылатын сайт жариялайды.

  1. 1

    Аккаунт ашыңыз

    GitHub-та тіркеліп, электрондық поштаңызды растаңыз.

  2. 2

    Репозиторий жасаңыз

    New repository батырмасын басып, жобаға атау беріңіз. GitHub Free үшін Public режимін таңдап, README қосыңыз.

  3. 3

    Файлдарды жүктеңіз

    Add file → Upload files арқылы index.html мен оған қажет CSS, JavaScript және медиафайлдарды бума құрылымын сақтап жүктеңіз. Commit changes батырмасын басыңыз.

  4. 4

    GitHub Pages-ті қосыңыз

    Settings → Pages → Deploy from a branch тармағын таңдаңыз. index.html түбірде болса, main → / (root) таңдап, Save басыңыз.

  5. 5

    Сілтемені тексеріп, жіберіңіз

    Сайт жарияланған соң, Settings → Pages бетіндегі Visit site сілтемесін ашыңыз. Тапсырманы телефоннан немесе жасырын терезеден тексеріп, сайт сілтемесін жіберіңіз.

  6. 6

    Codex-те QR-код жасаңыз

    Codex-ке сайттың толық сілтемесін беріп, QR-кодты PNG форматында сұраңыз. Камерамен сканерлеп, дұрыс бет ашылса, оқушыларға жіберіңіз.

Codex-ке сұраныс үлгісі

«[Сайт сілтемесі] үшін QR-код жаса. Оны qr.png файлына сақта».
